## Activer GitHub Pages (une fois)

1. Ouvrir https://github.com/hercouet/hercouet.github.io/settings/pages
2. **Source** : GitHub Actions
3. Relancer le workflow **Deploy GitHub Pages** si besoin

Les fichiers publics sont dans `famille-app/`.
